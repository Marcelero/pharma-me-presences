⚙️ Configuration Firebase requise

Firebase n'est pas encore configuré. Suivez ces étapes pour activer la base de données cloud dédiée à la Pharmacie de la Mé.

Étape 1 – Créer le projet Firebase Allez sur console.firebase.google.com → "Ajouter un projet" → Nommez-le pharma-me-presences
Étape 2 – Activer Firestore "Firestore Database" → "Créer une base de données" → Mode Production → Choisir une région (eur3 ou nam5)
Étape 3 – Configurer les règles Firestore Onglet "Règles" → Remplacez par :
rules_version = '2'; service cloud.firestore { match /databases/{database}/documents { match /pharma_reunions/{id} { allow read: if true; allow write: if true; } match /pharma_presences/{id} { allow read, write: if true; } match /pharma_membres/{id} { allow read, write: if true; } } }
Étape 4 – Coller la configuration Paramètres du projet → "Vos applications" → Ajouter une app Web → Copier les valeurs dans le bloc firebaseConfig de admin-pharma.html et scan-pharma.html
Étape 5 – Définir l'URL GitHub Pages Dans le bloc CONFIG, remplacez baseUrl par l'URL de votre dépôt GitHub Pages dédié
